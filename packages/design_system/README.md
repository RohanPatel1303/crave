# Design System

This package contains the app's shared design tokens, including colors, themes, and style primitives used across the product.

## What is included

- Color tokens and semantic color roles
- Light and dark theme definitions
- Shared UI styling values
- Reusable design system primitives for consistent app experiences

## Purpose

The goal of this package is to keep the UI consistent by centralizing design decisions in one place. Instead of repeating styling values across screens, the app consumes the tokens and themes defined here.

## Typical usage

- Use theme data for app-wide light and dark modes
- Consume color tokens for backgrounds, surfaces, text, and accents
- Build screens and widgets from standardized design values

This package helps maintain a cohesive design language across the Flutter app.
